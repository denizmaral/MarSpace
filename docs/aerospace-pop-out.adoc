// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace pop-out [-h|--help] [on|off] [--window-id <window-id>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}.

A popped out window floats above the others in the middle of its monitor, 1300 by 900 points (at most nine tenths
of the screen), on its workspace. Move it and resize it as you like: it pops out there again the next time.

Popped back in, it goes back to its tile, with its size. A window that was floating before goes back to where it was, a
window on a floating workspace floats like the others.

Without `on` or `off`, the command toggles. Like Omarchy's "pop window out" (Super + O), which pins the window too:
`aerospace pin` makes a popped out window come along to every workspace. Popped out windows are remembered when MarSpace
is restarted, with their tiles.
